# PDF Import Tracker

Tracks extraction progress per PDF, per table/step.

**Status codes:**
- `pending` — not started
- `done` — extracted and inserted into DB
- `verify` — data exists in DB but completeness/correctness unconfirmed
- `skip` — intentionally skipped (historical data already in DB)
- `error` — extraction attempted, failed; see notes
- `tbd` — table existence not yet confirmed (check ToC first)

**Processing order:** reverse chronological (2024 → 1986)

**No overflow file.** All data → `vizmerleg.db` only. `vizmerleg_inserts.sql` is a historical snapshot — NOT updated during extraction (per EXTRACTION_GUIDE.md §5).
Geometric lookup tables (tbl9 era B) are skipped — static reference data, no DB table.
See `EXTRACTION_GUIDE.md` for full INSERT patterns, station mapping, and data rules.
